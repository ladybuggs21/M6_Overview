Coffee Order Board Overview

Scenario: "A coffee order board — placed, making, ready, collected. Cannot skip a step"

This is a coffee order board where its purpose is to organize the customer's orders in letting them know where their order was placed, if it's being made, if it is ready, and also answers to when the customer collected their coffee order. To automate the pick-up process, after the barista completes the order and pushes it into the system, the machine will print out a QR-code to stick on the box/parcel. Later, when the customer comes to pick it up, they can scan the QR-code from their app at the machine, which checks the items, drops the matching order, and automatically marks it as "complete" or "picked up." This coffee order board would be useful for both customers who order coffee and baristas making orders, as it ensures that everyone is in order and that everyone is getting their orders.

The machine would start when someone either places an in-person or online order, basically starting the machine. Usually it would show on a screen if someone's order is started. If nothing has been placed, the screen would be blank, with subheadings showing placed, making, ready, and already collected. There would be no numbers necessarily, however, it could show the time of when the order was placed. It could also track time, and if the making takes too long (e.g., 10 mins), the system would push a clarifying or apologizing message to the user and also send a reminder to the baristas. Usually it would stay on all day while the coffee shop is open, only turning off when there is no business. As well as, next to the coffee order it would place the name of who ordered it to make it easier to locate. And depending on when it was placed, it would put the names in order to show when it was placed and by who.

If something goes wrong you might need to reset the machine, or there would be a light indicating that the machine needs to be reset.
